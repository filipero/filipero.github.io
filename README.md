# Filipe GitHub Pages

Simple static GitHub Pages site for hosting app seller files.

## Files

- `index.html` is the homepage.
- `app-ads.txt` is the standard file used by AdMob and most app ad networks.
- `apps-ad.txt` is included only because it was requested by name.

## GitHub Pages setup

1. Push this folder to a GitHub repository.
2. For a user GitHub Pages site, the repository should normally be named `YOUR_GITHUB_USERNAME.github.io`.
3. In GitHub, open Settings > Pages.
4. Set the source to `Deploy from a branch`, branch `main`, folder `/root`.
5. After deployment, confirm the file loads at `https://YOUR_GITHUB_USERNAME.github.io/app-ads.txt`.

The current seller entry is in `app-ads.txt`. Update it only if your ad network gives you a different line.
