Foire aux questions

Comment créer un tournoi ?

Touchez le bouton + sur l'écran d'accueil, choisissez le nombre de participants et un mode de nommage (noms manuels ou couleurs), puis touchez Démarrer.

Comment enregistrer le résultat d'un match ?

Touchez n'importe quel match dans le tableau ou la liste des matchs. Une feuille apparaît pour vous permettre de sélectionner le vainqueur et, si vous le souhaitez, d'enregistrer un score.

Puis-je modifier un résultat après l'avoir saisi ?

Oui. Touchez à nouveau le match et sélectionnez un autre vainqueur. Si le vainqueur a déjà avancé dans un tour ultérieur, une confirmation vous sera demandée — les tours suivants devront être rejoués manuellement.

Qu'est-ce que la petite finale ?

Lorsqu'elle est activée (4 participants minimum), les deux perdants des demi-finales disputent un match supplémentaire pour déterminer les 3e et 4e places. Activez-la sur l'écran de création du tournoi.

Puis-je jouer en équipes ?

Oui. Lors de la création d'un tournoi ouvert aux participants, choisissez Doubles, Trios, Foot à 5 ou une taille d'équipe personnalisée. Au fur et à mesure que les gens rejoignent le salon, l'application compose les équipes dans l'ordre, et vous pouvez renommer n'importe quelle équipe avant de verrouiller le tableau.

Comment lancer une revanche ?

Sur un tournoi terminé, balayez-le vers la gauche dans la liste des tournois et touchez Revanche. Un nouveau tournoi avec les mêmes participants sera créé.

Comment supprimer un tournoi ?

Balayez le tournoi vers la gauche dans la liste et touchez Supprimer, ou ouvrez le tournoi et utilisez l'option de suppression dans le menu.

Mes données sont-elles stockées dans le cloud ?

Par défaut, non — les tournois sont stockés localement sur votre appareil. Cela change uniquement si vous choisissez de partager un tournoi ou de rejoindre celui de quelqu'un d'autre : les données de ce tournoi (noms, réglages et résultats) sont alors synchronisées via Firebase afin que tous les participants et spectateurs restent synchronisés. Consultez notre Politique de confidentialité pour en savoir plus.

Comment inviter des personnes à un tournoi ?

Ouvrez le salon du tournoi et partagez son QR code ou son lien. Toute personne avec qui vous le partagez peut rejoindre depuis son propre appareil, ou le regarder en direct.

Comment rejoindre le tournoi de quelqu'un ?

Scannez le QR code qu'on vous montre, ou ouvrez le lien qu'on vous envoie. Scanner un code utilise votre appareil photo ; ouvrir un lien fonctionne sans.

Pourquoi l'application demande-t-elle l'accès à l'appareil photo ?

Uniquement pour scanner le QR code permettant de rejoindre un tournoi. Rien n'est photographié, enregistré ou envoyé — l'appareil photo sert exclusivement à lire le code. Vous pouvez refuser et rejoindre via un lien à la place.

Puis-je regarder un tournoi déjà commencé ?

Oui. Si vous scannez ou ouvrez le lien d'un tournoi après le verrouillage du tableau ou la fin du tournoi, vous le rejoindrez en mode Spectateur (lecture seule) et verrez le tableau se mettre à jour en direct.

Qu'est-ce que le mode présentation ?

Une vue plein écran du tableau, en lecture seule, conçue pour un iPad installé sur place. Les touches sont désactivées pour que les passants ne puissent pas modifier les résultats, et l'écran reste allumé pendant l'affichage. Ouvrez-le depuis l'icône TV dans la barre d'outils d'un tournoi.

Comment signaler un tournoi inapproprié ?

Lorsque vous consultez un tournoi partagé, utilisez l'option Signaler et choisissez un motif (nom offensant, contenu inapproprié, spam ou autre). Vous pouvez également retirer le tournoi de votre propre appareil. Les signalements nous sont transmis pour examen.

Comment supprimer les publicités ?

Touchez le bouton Supprimer les pubs dans un tournoi pour regarder une courte vidéo avec récompense et supprimer les publicités pour cette session de tournoi.
